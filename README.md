# 🐍 Tkinter Cheatsheet

**A beginner-friendly collection of Python Tkinter examples for learning desktop GUI development.**

Learn how to create windows, add widgets, handle user interactions, and arrange interface elements using simple Python scripts.

## 📌 Overview

Tkinter is Python's standard library for building graphical user interfaces (GUIs). This repository contains small, focused examples that help beginners understand its basic components and build a foundation for desktop application development.

Each example demonstrates a specific concept and can be explored independently.

## ✨ Features

- 🪟 **Window Creation** — Create and configure application windows.
- 🔘 **Buttons** — Add buttons and connect them to functions.
- 📝 **Text Input** — Accept user input through entry fields.
- 📄 **Text Display** — Display labels and text areas.
- 📐 **Grid Layout** — Arrange widgets using the grid geometry manager.
- 💬 **Message Popups** — Display information and messages in dialog boxes.
- 📚 **Simple Examples** — Learn individual concepts through separate Python files.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Tkinter, usually included with standard Python installations

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abdurrahmancce/Tkinter-Cheatsheet.git
```

**2. Navigate to the project directory**

```bash
cd Tkinter-Cheatsheet
```

**3. Run an example**

```bash
python create_window.py
```

You can run any of the other `.py` files individually to explore different Tkinter concepts.

> **Note:** On Linux, you may need to install the Tkinter package separately. On Ubuntu or Debian, use `sudo apt install python3-tk`.
